# Stock Portfolio Tracker 📈

A beginner-friendly Python program that helps users track the value of their stock holdings.

## What it does 💻

- Shows a list of available stocks and their prices
- Accepts stock symbols and share quantities
- Checks that quantities are positive whole numbers
- Adds quantities when the same stock is entered more than once
- Calculates each holding’s value and the total investment
- Saves the portfolio summary to `portfolio.csv` if the user chooses

## How to run ▶️

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:
   python stock_portfolio_tracker.py
